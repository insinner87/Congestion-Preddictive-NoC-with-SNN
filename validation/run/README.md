# Simulation output

`PROJECT-RESULTS.txt` is the single consolidated report generated by
`validation\run-project.ps1`. Detailed logs and compiled outputs for that
full run are saved to a timestamped `full-project-*` directory.

The single-design scripts `validation\run-router.ps1` and
`validation\run-mesh.ps1` save their outputs in timestamped `standalone`
subdirectories. `run-all.ps1` is the underlying nineteen-test runner and writes
to `reorganized\` by default, or to a caller-selected directory.

The existing `mesh-west-first\` output is preserved from an earlier
validation run. Saved earlier results are kept separately under
`validation\results\`.
